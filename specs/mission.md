# Mission

## Purpose

Spring PetClinic is a **learning portfolio project** designed to help Spring developers understand and apply modern Spring Boot conventions and best practices.

## Target Audience

**Spring developers** — engineers who want to study a well-structured Spring Boot application to learn:

- Domain-driven design with Spring Data JPA
- Controller and service-layer patterns
- Testing strategies (integration, Testcontainers, mutation, contract)
- API-first development with a REST layer
- Modern frontend integration (Vue.js)
- Containerization and CI/CD with GitHub Actions

## Goals

1. **Be a reference implementation** — honest, idiomatic Spring Boot code that others can learn from and adapt.
2. **Demonstrate progressive modernization** — show how a traditional server-rendered app can evolve toward an API-first architecture with a modern frontend.
3. **Teach developer workflows** — containerization, automated testing, and CI/CD pipelines are first-class concerns, not afterthoughts.

## Anti-Goals

- This is **not** a production veterinary clinic management system. Features should demonstrate patterns, not attempt clinical completeness.
- This is **not** a Spring Framework tutorial. We assume familiarity with Java and Spring basics; the focus is on practical project structure and modern tooling.
